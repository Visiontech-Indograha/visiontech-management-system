## 7. Langkah deploy baru (akibat audit)

1. Variabel lingkungan API produksi:
   - `APP_ENV=production`
   - `JWT_PRIVATE_KEY_HEX`
   - `DOC_SIGNING_KEY_HEX` (atau KMS)
   - `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` (bukan bawaan)
   - `MINIO_PUBLIC_URL=https://<domain aplikasi>`
2. Caddy (`web/Caddyfile`): `MINIO_BUCKET` (bawaan `vms-files`) dan `MINIO_UPSTREAM` (bawaan `minio:9000`).
3. Migrasi: `alembic upgrade head` (sampai `0011_views_org_local_date`).
4. APK rilis: HTTPS wajib. Uji LAN sementara: `flutter build apk --release -PallowCleartext=true`.
5. Bangun ulang image API: dependensi baru (WeasyPrint 70, python-multipart 0.0.31, Jinja2 3.1.6).
