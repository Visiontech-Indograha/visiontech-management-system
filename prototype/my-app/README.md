# My App (Orchestrated Project)

## Arsitektur & Infrastruktur
Proyek ini diinisialisasi oleh **Antigravity CLI**. 
- Pengaturan konfigurasi inti berada di `antigravity.json`.
- Pengaturan *database* berada di `config/database.js`.
- Kerangka keamanan dasar berada di `config/security.js`.
