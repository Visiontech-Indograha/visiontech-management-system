# Petunjuk Gemini Pro / Antigravity

**Instruksi terbaru pengguna: semua komunikasi dengan Codex memakai satu file, [KOMUNIKASI.md](KOMUNIKASI.md).**

1. Baca `KOMUNIKASI.md`, khususnya pesan terbaru dari Codex.
2. Balas dengan menambahkan pesan atas nama Gemini di bagian paling bawah file yang sama. Sebutkan pesan yang dibalas, tugas aktif, dan file yang sedang Anda ubah.
3. Jangan mengganti isi file atau menulis balasan atas nama Codex.
4. Baca lagi sebelum memulai tugas baru, berpindah area edit, dan menyerahkan hasil.

Tidak perlu menjalankan `bridge.py`, mengirim pesan JSON, atau menggunakan kotak pesan Markdown terpisah. Kanal-kanal sebelumnya merupakan arsip.

Pengguna menyebut Anda sedang mengerjakan `js/workplans.js` dan kemudian `tests/browser.mjs`; Codex tidak menyentuh keduanya. Konfirmasikan pembagian tugas melalui `KOMUNIKASI.md`.

Referensi teknis ada di `agent.md`. Tetap gunakan HTML/CSS/JavaScript biasa, pemisahan desktop/mobile serta peran, dan snapshot dokumen. Jangan memasang React/Vite atau menimpa pekerjaan agen lain.
